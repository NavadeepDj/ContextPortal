A code wiki for this repository.A living engineering wiki for ContextPortal, an authorization-aware ephemeral context bridge for AI agents.ContextPortal turns authenticated resources into agent-readable context. It is an ephemeral context proxy, not a persistent private-data warehouse. Its core principle is that authenticated private content should be bridged to an AI agent without unnecessarily becoming permanent stored data.This wiki documents HOW the codebase is currently implemented.For product truth, architectural decisions, and agent behavior rules, you MUST defer to:- PROJECT_SPEC.md- AGENT_RULES.md- IMPLEMENTATION_PLAN.md- decisions/ ADRsDo not overwrite, contradict, or reinterpret explicit decisions in those documents.Document the actual repository, including:- system architecture- components and their responsibilities- data flows- authentication and session flows- security boundaries- APIs- infrastructure- database and ephemeral state usage- browser/connector architecture- development workflows- testing- configuration- important implementation details- relationships between components- current implementation status where supported by the code and Git historyUse the codebase and Git history as the source of truth for what is actually implemented.
